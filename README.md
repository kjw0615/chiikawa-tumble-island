# 먼작귀 데굴데굴 섬 (Chiikawa Tumble Island) - 웹 버전

치이카와(먼작귀) 캐릭터 수박 게임 스타일 물리 퍼즐의 웹 빌드(Godot 4.7 Web export)입니다. 소스는 [chiikawa-watermelon](https://github.com/kjw0615/chiikawa-watermelon)에 있습니다.

> 비영리 팬메이드 게임입니다. Chiikawa의 모든 권리는 Nagano 및 치이카와 제작위원회에 귀속됩니다.

## 웹에서 플레이하기
1. 브라우저로 `index.html`을 정적 웹 서버에서 엽니다. (파일을 더블클릭하면 wasm 로딩이 막힙니다. 예: 이 폴더에서 `python -m http.server 8000` 후 `http://localhost:8000`)
2. 최신 Chrome/Edge/Firefox를 권장합니다. 소리는 화면을 한 번 클릭한 뒤 나옵니다.
3. 로그인/랭킹은 인터넷 연결이 필요합니다. 비로그인으로도 플레이할 수 있지만 점수는 저장되지 않습니다.

## 게임 설명
같은 캐릭터 노드 두 개를 부딪혀 합치면 다음 단계(11단계까지)로 진화합니다. 노드가 위쪽 선을 넘은 채로 쌓이면 게임 오버이고, 11단계끼리 합치면 사라지고 +100점입니다. 합체로 모은 게이지로 아이템 4종(엉덩이 흔들기, 캐릭터 교체권, 명검 투하, 음식 분수)을 쓸 수 있습니다.

## 조작법
- 마우스 이동/누른 채 이동: 위치 정하기, 놓으면 떨어집니다
- 숫자키 1~4 또는 스킬 버튼: 아이템 사용 (명검 조준 중 우클릭/ESC로 취소)
- ESC: 일시정지 메뉴

## 파일
`index.html`, `index.js`, `index.wasm`, `index.pck`(게임 데이터), `index.icon.png`/`index.apple-touch-icon.png`(파비콘), `index.png`(로딩 화면), 오디오 worklet 2개.
